# 定时任务说明

配置入口：`scheduled_jobs/jobs/schedule_config.py`

服务启动：

```bash
./start_scheduled_jobs.sh
# 或
python main.py --port 7331
```

---

## 通用规则

| 项 | 说明 |
|----|------|
| **触发条件** | 仅当「今天」在 `economic.trade_dates` 中为交易日时才执行 |
| **数据日** | 写入 **T-1（上一交易日）** 的截面，`date` 字段为 `YYYY-MM-DD` |
| **Mongo 地址** | 默认 `192.168.110.199:27018` |
| **写库别名** | `wonderwz27018_rw`（可用环境变量 `MONGO_TRADE_ALIAS` 覆盖） |
| **业务库** | `basic_rq` |
| **日志库** | `basic_rq_logs.rq_logs`（每次任务执行后写入） |
| **邮件** | 根目录 `.env` 配置 `ALPHA_NOTIFY_*`，任务成功/失败均通知 |

手动触发示例：

```text
http://192.168.110.199:7331/run?job=rq_quarterly
http://192.168.110.199:7331/run?job=all
```

## 各任务说明与字段

### 1. 09:03 · rq_base_info

**作用**：从米筐拉取全市场 A 股基础信息，建立当日 **universe**（后续多数任务依赖 `code_rq` 列表）。

**落库**：`basic_rq.rq_base_info`

| 字段 | 含义 |
|------|------|
| `date` | 交易日，`YYYY-MM-DD` |
| `code` | 展示代码，如 `SH600000` / `SZ000001` |
| `code_rq` | 米筐合约，如 `600000.XSHG` |
| `trade_status` | 是否可交易：1=正常，0=停牌 |
| `riskwarning` | ST 标记：1=ST，0=非 ST |
| `list_days` | 上市天数 |

---

### 2. 09:05 · rq_basic_financial

**作用**：拉取市值、股本及部分 TTM 财务因子，写入基本财务表。

**落库**：`basic_rq.rq_basic_financial`

| 字段 | 含义 |
|------|------|
| `date` | 交易日 |
| `code` / `code_rq` | 股票代码 |
| `mkt_cap_ard` | 总市值 |
| `total_shares` | 总股本 |
| `free_float_shares` | 自由流通股本 |
| `or_ttm` | 营业收入 TTM |
| `gr_ttm` | 营业总收入 TTM |
| `netprofit_ttm` | 净利润 TTM |
| `operatecashflow_ttm` | 经营现金流 TTM |

---

### 3. 09:07 · rq_in_index

**作用**：按米筐指数成分，标记每只股票是否属于宽基指数成分股。

**落库**：`basic_rq.rq_base_index`

| 字段 | 含义 |
|------|------|
| `date` | 交易日 |
| `code` / `code_rq` | 股票代码 |
| `in_SZ50` | 是否上证 50 成分（0/1） |
| `in_HS300` | 是否沪深 300 成分 |
| `in_ZZ500` | 是否中证 500 成分 |
| `in_ZZ1000` | 是否中证 1000 成分 |
| `in_ZZ2000` | 是否中证 2000 成分 |

---

### 4. 09:10 · rq_swl2

**作用**：拉取申万二级行业分类及各行业成分股列表。

**落库**：`basic_rq.rq_daily_indusSWL2`

| 字段 | 含义 |
|------|------|
| `date` | 交易日 |
| `indus_code` | 申万二级行业代码 |
| `name` | 行业名称 |
| `stocks` | 该行业成分股列表（`code_rq`） |

---

### 5. 09:13 · rq_swl2_price

**作用**：申万二级行业指数及成分股的日 K 价量。

**落库**：`basic_rq.rq_daily_indusSWL2_price`

主要字段：`date`、行业/股票标识、开高低收、成交量、成交额等（与日线结构类似）。

---

### 6. 09:15 · rq_bench

**作用**：拉取基准指数日 K 行情（对标 Wind bench）。

**落库**：`basic_rq.rq_bench`

| 字段 | 含义 |
|------|------|
| `date` | 交易日 |
| `code` | Wind 风格指数代码，如 `000300.SH` |
| `code_rq` | 米筐合约 |
| `open` / `high` / `low` / `close` | OHLC |
| `pre_close` | 前收 |
| `pct_chg` | 涨跌幅 |
| `volume` | 成交量（百万股） |
| `amt` | 成交额 |
| `rq_bench_substitute` | 是否用替代指数（如 881001.WI → 399317） |

### 7. 09:18 · rq_daily_price

**作用**：全市场股票 **不复权** 日 K 价量。

**落库**：`basic_rq.rq_daily_price_none`

| 字段 | 含义 |
|------|------|
| `date` | 交易日 |
| `code` / `code_rq` | 股票代码 |
| `open` / `high` / `low` / `close` | OHLC |
| `prev_close` | 前收 |
| `volume` | 成交量 |
| `total_turnover` | 成交额 |
| `limit_up` / `limit_down` | 涨跌停价 |

---

### 8. 09:20 · rq_quarterly

**作用**：

1. 从米筐拉 **PIT 季报**真实快照（前一交易日截面）
2. 对最近约 30 个交易日做 **ffill**，按 `rq_base_info` universe 逐票补齐缺口

**落库**：`basic_rq.rq_quarterly`

| 字段 | 含义 |
|------|------|
| `date` | 数据日（前一交易日） |
| `code` / `code_w` / `code_rq` | 股票代码（Wind / 米筐格式） |
| `rptdate` | 报告期末日，如 `2024-09-30` |
| `stm_issuingdate` | 披露日（PIT 关键字段） |
| `monetary_cap` | 货币资金 |
| `minority_int` | 少数股东权益 |
| `tot_equity` / `tot_assets` / `tot_liab` | 股东权益 / 总资产 / 总负债 |
| `interestexpense_ttm` | 利息支出 TTM |
| `gc_ttm2` / `or_ttm2` / `netprofit_ttm2` | 营业总成本 / 营收 / 净利润 TTM |
| `ebit2_ttm` | EBIT TTM |

**邮件/日志统计**（示例）：

```text
季报更新完成 pre=2026-05-29 | 拉取 5204 条 | 拟补 156 条 | 总插入 5360 条
```

| 统计项 | 含义 |
|--------|------|
| 拉取 | 米筐 PIT 真实写入行数 |
| 拟补 | ffill 新插入行数（复制上一有效快照） |
| 总插入 | 拉取 + 拟补 |

---

### 9. 09:25 · rq_yearly

**作用**：

1. 从米筐拉 **PIT 年报**（税负 + 审计意见）
2. 对最近约 30 个交易日做 **ffill** 补齐

**落库**：`basic_rq.rq_yearly`

| 字段 | 含义 |
|------|------|
| `date` | 数据日（前一交易日） |
| `code` / `code_w` / `code_rq` | 股票代码 |
| `rptdate` | 报告期（年报对应季度末） |
| `stm_issuingdate` | 披露日 |
| `stmnote_tax` | 税负率（所得税/利润总额） |
| `stmnote_audit_category` | 审计意见：1=无保留类，0=其他 |

**邮件/日志统计**：同季报（拉取 / 拟补 / 总插入）。

---

### 10. 09:35 · rq_minute

**作用**：从米筐拉取全市场 **1 分钟线**，写入按年份分表的 Mongo 集合。

**落库**：`rq_minute.rq_minute_none_YYYY`（`YYYY` 为数据日年份，如 2025 年数据 → `rq_minute_none_2025`）

| 字段 | 含义 |
|------|------|
| `date` | 交易日，`YYYY-MM-DD` |
| `time` | 分钟时刻，`HH:MM:SS` |
| `code` / `code_rq` | 股票代码 |
| `open` / `high` / `low` / `close` | 1 分钟 OHLC |
| `volume` | 成交量 |
| `total_turnover` | 成交额 |

**依赖**：09:03 `rq_base_info` 须已写入 T-1 的 `code_rq` 列表。

**手动触发**：`http://192.168.110.199:7331/run?job=rq_minute`

---

### 11. 08:45 · rq_data_quality_check

**作用**：在当日日线/分钟线更新完成后，对 **最近 2 个交易日**（T-2 ~ T-1）执行 `check_historical_data` 质量检查（唯一性、字段完整、日期覆盖）。

**检查范围**：`basic_rq` 9 表 + `rq_minute.rq_minute_none_YYYY`（按区间年份自动展开）。

**报告落盘**（不写业务库）：

| 文件 | 路径 |
|------|------|
| 检查报告 | `check_historical_data/reports/scheduled_YYYYMMDD_HHMMSS.txt` |
| 问题 _id 明细 | 同目录 `scheduled_*_issue_ids.txt` |

**日志**：`basic_rq_logs.rq_logs`（`job_id=rq_data_quality_check`）

**邮件**：成功/失败均发送，正文含汇总与报告路径（依赖 `.env` 中 `ALPHA_NOTIFY_*`）。

**环境变量**（可选）：

| 变量 | 默认 | 说明 |
|------|------|------|
| `DATA_QUALITY_MONGO_ALIAS` | `wonderwz27018_ro` | 只读检查用 Mongo 别名 |
| `DATA_QUALITY_SKIP_MINUTE` | 空 | `1` = 跳过 rq_minute（缩短耗时） |

**手动触发**：`http://192.168.110.199:7331/run?job=rq_data_quality_check`

### 12. 10:00 · rq_minute_backfill（历史倒序 · 按月批量）

**作用**：每天 **10:00** 启动一次，在 **14:40 前**持续运行（非每 20 分钟触发一次）：

1. 查询所有 `rq_minute_none_*` 的 **最大 `date`**（anchor）
2. 确定补数区间 `[起点, anchor 前最后交易日]`
3. 按 **自然月倒序**（离 anchor 最近的月份优先）批量落库
4. 每月：读 `basic_rq.rq_base_info` lookup → 逐交易日拉 1m → 写入 `rq_minute_none_YYYY`
5. 已有数据的交易日自动跳过；14:40 或 RQ 配额达阈值时暂停，次日 10:00 继续

**实现**：对齐 `rq_getRangeDailyPriceLongrun.py` 的按月分段 + `rq_getRangeMinPrice.run_minute_range_to_mongo`

**落库 / 索引**：同 09:35

**环境变量**：

| 变量 | 默认 | 说明 |
|------|------|------|
| `RQ_MINUTE_BACKFILL_START` | `2015-01-05` | 历史起点 |
| `RQ_MINUTE_BACKFILL_FORCE` | 空 | `1` = 忽略 10:00–14:40 窗口 |

**手动**：

```bash
cd rq_minute_daily
python backfill_rq_minute.py --force
```

**HTTP**：`/run?job=rq_minute_backfill`

**重启说明**：cron 仅在每天 **10:00** 触发一次；若在 **10:00–14:40 之间**重启服务，启动时会 **自动补跑** 一次。若在 10:00 之前重启（如 06:15），需等到当日 10:00（服务需保持运行）。

## 执行依赖关系

```text
09:03 rq_base_info          ← 必须先跑，提供当日 code_rq universe
  ├─ 09:05 rq_basic_financial
  ├─ 09:07 rq_in_index
  ├─ 09:18 rq_daily_price
  ├─ 09:20 rq_quarterly
  ├─ 09:25 rq_yearly
  └─ 09:35 rq_minute

10:00 rq_minute_backfill（10:00 启动，14:40 前按月倒序批量补历史）

09:10 rq_swl2 → 09:13 rq_swl2_price   （申万链路，相对独立）

09:15 rq_bench                        （基准指数，相对独立）
```

## 日志与邮件

每次任务完成后写入 `basic_rq_logs.rq_logs`，主要字段：

| 字段 | 含义 |
|------|------|
| `run_at` | 执行时间 |
| `job_id` | 如 `rq_quarterly` |
| `task_name` | 如 `update_rq_quarterly` |
| `schedule_time` | 计划时刻，如 `09:20` |
| `ok` | 是否成功 |
| `skipped` | 是否因非交易日跳过 |
| `message` | 摘要（含拉取/拟补统计） |
| `detail` | JSON 详情（`target_date`、`pulled` 等） |

邮件标题示例：`[rq_quarterly] 执行成功` / `[rq_quarterly] 执行失败`

## 修改定时

增删任务：编辑 `schedule_config.py` 的 `SCHEDULE_ENTRIES`，并在 `jobs/registry.py` 注册 runner。

季报/年报历史补全（非定时任务）：见 `rq_history_backfill/季报年报运行指南.md`。
